# Camp Lohikan 3D: how it fits together

## Pieces
- **Review site** (this repo, GitHub Pages): https://brickwaii.github.io/lohikan-review/ needs no login.
  - The backend is Google Apps Script (`backend/`) writing to Henry's Google Sheet.
  - Content comes from `views.json`, which is generated by `gen_views.py` (working copy, not in this repo yet).
  - `views.json` `changes` is preserved across regenerations.
- **Model** (`model/`): three.js viewer.
  - `campbuildings.js` holds every generic building and extra (pool, pavilions, fences, benches...).
  - `sportscenter.js` holds the Sports Center, the circus, the gym, the canteen and the dance studio.
- **Henry's review flow:**
  - Pins on 360s and stills.
  - The "What's changed" page, where he approves a change or sends it to rework.
  - Per-pin Fixed / Not fixed.
  - A new change item lists `replaces: ['vX-i']` for the rework it answers. It shows only the pins that are still open.

## Coordinates
- Map pixels → viewer world: `x = mx − 1612`, `y = elev − 440`, `z = −(my − 1606)`. +x is east and −z is north.
- Generic extras: `local z = −dy`, and `rotation.y = θ` points local +x to compass bearing `90 − θ`.
- Sports Center local frame: `map = (1762.1 + x, 1610.6 − z)`. In the circus code `s = −1` is the north wall and `s = +1` the south.
- Pano column for a compass bearing: `col = ((bearing + shift)/360 + 0.5) · W`. The shifts are in `pano/shifts.json`.

## Standing rules (from Henry)
- Model permanent structure only: no seasonal or stored equipment. The Oct 2026 Ghost photos show storage mode.
- Don't post new realistic images or photo scans until Henry has reviewed them.
- Never permanently delete unique content. Move it to a `_to_delete` or rejected folder instead.
- Keep token use lean. No check-ins 11 PM–7 AM Pacific.
- Laptop jobs: keep the system awake with the worker's SetThreadExecutionState only. The screen may go dark. Never change Windows power settings.
- Don't scrape the private Facebook group. Treat any cookies file as a password.

## Known pitfalls
- In `campbuildings.js` each building type is a separate `if (e.type === ...)` block. Check you are inside the right one. In v5–v7 the pool benches were edited inside the ballfield block by mistake, so the fix never appeared.
- GitHub Pages caches HTML for about 10 minutes. Tell Henry to hard refresh.
- Headless renders: use `wait_for_timeout`, not `wait_for_function`.
